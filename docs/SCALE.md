# 2D world scale bible (film/studio_*.js) - every prop/background MUST follow this
Unit: one standing character = ~330 world units tall (feet y=0, head top ~ -330). 1 metre ~ 190 units.
| thing | size (units) | note |
|---|---|---|
| door | 170 w x 400 h | person fits with headroom |
| window (near, layer 1) | 120 x 140 | far layers use parallax, may look smaller |
| car (side) | 850 long x 270 high, wheel dia 124 | 2.6 persons long; draw on road lane y 300+ |
| street lamp | 760 high | 2.3 persons |
| desk | 280 w x 130 h | |
| bed | 360 w, top at -150 | |
| house | 560 w x 620 wall + roof | 2 storeys |
| bank / big building | 520+ w x 640+ h | columns >= 600 tall |
| coin (flying FX) | r 12 | stylised, may exceed real size |
| tree | trunk 330, canopy 400 | |
| ship, rocket, whale: large vs person (ship 6x, rocket 10x, whale 8x) | | |
Rules: (1) never draw a prop smaller than a person if it is bigger in reality. (2) background layers use parallax 0.2-0.7 and may be stylised; anything at layer 1 is true scale. (3) cast shadows under every object. (4) characters stay in frame; camera is one continuous glide.
References: Toon Boom relative-size guidance (consistent size between characters, props, backgrounds), Blender Studio "Sprite Fright" (chunky simple shapes, simplexity), Open Peeps / Humaaans CC0 vector style.
